# Walkthrough video script — v0.1 baseline

Target: 5-10 minutes, screen recording + narration. Not a polished demo reel — a record of the real thing working, for whoever looks back at this later. The video file itself doesn't belong in git (binary size) — record it, upload it wherever makes sense (shared drive, Loom, etc.), and drop the link into this baseline's [`README.md`](../README.md).

## Suggested beats

1. **Cold open (30s).** One sentence on what this is: "Organizational Singularity, the internal platform SoverAIgn is building to run its own OIQ methodology on itself. This is the first time it's actually done that, end to end."

2. **Sign in (30s).** Show real Entra ID sign-in — this isn't a mocked login.

3. **The organization (30s).** Open SoverAIgn Solutions. Note it's a real org record, not seed/demo data.

4. **The assessment (1-2 min).** Open the completed assessment. Scroll through a few real answered questions if useful — no need to show all 44. Point out the reassessment lineage if there's a second assessment to show.

5. **The OIQ profile (1-2 min).** This is the centerpiece. Walk through the 11 dimensions, call out Sensing at 2.0/Emerging as the standout low score, and explain in one sentence what the composite average is and isn't (secondary/internal reference, not the primary result — the 11-dimension profile is).

6. **Intelligence Debt (1-2 min).** Open one of the two auto-detected findings. Show the "why this was detected" section — the actual rule and threshold, not a black box. Show it moving from Detected through the review workflow to Approved, with the rationale that was written.

7. **Roadmap (1 min).** Show RM-003 and RM-004, converted directly from the approved findings — not manually re-typed.

8. **Executive report (1-2 min).** The full report page, tying it all together: OIQ profile, evidence summary, top Intelligence Debt, prioritized roadmap. This is the actual Phase 1 exit criterion rendered as one page.

9. **Close (30s).** One sentence on what's next: Phase 1 is being frozen as a baseline here; Phase 2 (governed AI assistance — Prometheus, Atlas) is next.

## What NOT to spend time on

Don't demo the Azure infrastructure or the deployment mechanics — this video is about the product working, not the plumbing. That's covered in the compliance report and deviations doc instead.
